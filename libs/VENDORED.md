# Vendored dependencies

Everything here is pinned source, no package manager. The two sokol halves are
pinned **together**: sokol-shdc generates code for a specific sokol_gfx API, so
bumping one without the other can produce a header that does not match.

| What | Version |
|---|---|
| `libs/sokol/*.h` | floooh/sokol master (copied 2026-11-12) |
| `tools/sokol-shdc` | built from floooh/sokol-tools `f1dcd17` |
| stb | `libs/stb` (stb_image, stb_image_write, stb_perlin, …) |

`src/shaders.h` was generated by:

    tools/sokol-shdc -i src/shaders.glsl -o src/shaders.h -l metal_macos:glsl410 -f sokol

Source strings, not bytecode: `-b` needs the Metal toolchain
(`xcodebuild -downloadComponent MetalToolchain`), which is not installed here.
Adding `-b` later is a one-flag change in `tools/shaders.sh`.
